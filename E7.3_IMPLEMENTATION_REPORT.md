## 4. Precondition Grammar & Epistemological State Resolution

The `RestrictedPreconditionEvaluator` parses declarative state predicates (e.g. `projector.power == true and ac.target_temperature == 23`).

### AST Whitelist Rules:
- Permitted AST nodes: `Compare`, `BoolOp`, `UnaryOp`, `Attribute`, `Name`, `Constant`, `List`, `Tuple`, `Set`, `Eq`, `NotEq`, `Lt`, `LtE`, `Gt`, `GtE`, `In`, `NotIn`, `And`, `Or`, `Not`.
- Forbidden AST nodes: `Call`, `Import`, `Subscript`, `Lambda`, `Dict`, `ListComp`, `Exec`, `Eval`. Any attempt to call functions or execute code raises `INVALID_PRECONDITION` immediately.

### Epistemological Truth Table:
| Observed State Provenance | Freshness TTL Window | Precondition Value vs Reality | Precondition Evaluation Result |
|---|---|---|---|
| `Provenance.OBSERVED` | Within TTL ($t \le \text{TTL}$) | Matches target | `PreconditionStatus.SATISFIED` |
| `Provenance.OBSERVED` | Within TTL ($t \le \text{TTL}$) | Differs from target | `PreconditionStatus.NOT_SATISFIED` |
| `Provenance.UNKNOWN` | Any | Any | `PreconditionStatus.UNKNOWN_STATE` (Fails Closed) |
| Any | Expired ($t > \text{TTL}$) | Any | `PreconditionStatus.STALE_STATE` (Emits Warning / Fails Closed) |
